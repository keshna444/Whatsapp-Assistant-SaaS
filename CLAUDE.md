# Change Website Logo

## Task
Replace the current website logo with the new logo provided.

## Requirements
- Update the logo across the entire website.
- Ensure the new logo appears correctly on:
  - Navbar
  - Login/Register pages
  - Dashboard
  - Footer
  - Browser favicon (if applicable)
- Maintain responsive sizing for desktop and mobile devices.
- Preserve the website’s current styling and alignment.
- Optimize the logo image for fast loading.

## File Handling
- Remove or replace the old logo assets.
- Store the new logo inside the appropriate assets/images folder.
- Update all references/imports pointing to the old logo.

## Additional Notes
- Do not break existing layouts.
- Keep spacing and UI clean after replacing the logo.
- Use best practices for image rendering and responsiveness.

## Expected Outcome
The website should fully display the new branding/logo consistently across all pages and devices.
